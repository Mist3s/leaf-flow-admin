# Leaf Flow Admin

Небольшая фронтенд-админка для работы с API `https://app.zavarka39.ru/api/`.

## Возможности
- Экран авторизации с вводом bearer-токена (хранится локально без дополнительных проверок) и автоматическим переходом в каталог после сохранения.
- Каталог товаров из `/v1/catalog/products` с фильтром по категории и поиску, карточками товаров и быстрыми переходами в редактирование.
- Создание товара одним запросом с указанием ID, изображением (base64 без префикса `data:`); картинка автоматически сжимается и ресайзится до 1600px.
- Категорию можно выбрать только из списка `/v1/catalog/categories` (форма создания/редактирования).
- Загрузка товара по ID из каталога, редактирование основных полей и замена изображения.
- Управление упаковками: добавление, обновление, удаление через admin-эндпоинты.
- Адаптивный интерфейс под десктоп и мобильные устройства.

## Быстрый старт
```bash
npm install
npm run dev
```
Dev-сервер откроет статику из `src` на http://localhost:4173.

## Сборка
```bash
npm run build
```
Собранные файлы окажутся в `dist/` (без зависимостей, чистый HTML/CSS/JS).

## CI/CD
Workflow `.github/workflows/deploy.yml` собирает проект и выкладывает его на GitHub Pages из ветки `main`.

## Конфигурация
- API база зашита в `src/main.js` (`https://app.zavarka39.ru/api`).
- Токен хранится в `localStorage` под ключом `leaf-flow-admin-token`.
