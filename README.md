# Leaf Flow Admin

Небольшая фронтенд-админка для работы с API `https://app.zavarka39.ru/api/`.

## Возможности
- Авторизация по bearer-токену (токен сохраняется локально без дополнительных проверок).
- Создание товара одним запросом с изображением (base64) и списком упаковок/вариантов.
- Загрузка товара по ID, редактирование основных полей и замена изображения.
- Управление упаковками: добавление, обновление, удаление через admin-эндпоинты.
- Адаптивный интерфейс под десктоп и мобильные устройства.

## Быстрый старт
```bash
npm install
npm run dev
```
Dev-сервер откроет статику из `src` на http://localhost:4173.

## Сборка
```bash
npm run build
```
Собранные файлы окажутся в `dist/` (без зависимостей, чистый HTML/CSS/JS).

## CI/CD
Workflow `.github/workflows/deploy.yml` собирает проект и выкладывает его на GitHub Pages из ветки `main`.

## Конфигурация
- API база зашита в `src/main.js` (`https://app.zavarka39.ru/api`).
- Токен хранится в `localStorage` под ключом `leaf-flow-admin-token`.
